## 部署咨询 - backtester_backend 上线腾讯云 Lighthouse

- 项目：FastAPI + Uvicorn + Pydantic Settings，Python 3.11+
- 用户刚购买腾讯云 Lighthouse 服务器，需要完整部署指引
- 提供了完整部署流程：
  1. apt 安装 Python 3.11 / git / nginx
  2. git clone 到 /srv/backtester-backend
  3. 虚拟环境 + pip install -e .
  4. .env 配置（APP_ENV=production, APP_HOST=127.0.0.1, APP_PORT=8000）
  5. systemd 服务托管（backtester.service）
  6. Nginx 反向代理（80端口 → 127.0.0.1:8000）
  7. 腾讯云控制台防火墙放行 80/443
  8. 可选 certbot HTTPS
- 架构：客户端 → Nginx(80) → Uvicorn(127.0.0.1:8000) → FastAPI
